# Audits archive

Point-in-time audit reports and post-mortems. Each file here is a **dated
snapshot** — it captures findings as of the date in its name and is not kept up
to date afterward.

For the *living* audit tracker (per-batch progress, current blockers) see
`docs/AUDIT_STATE.md`. For the current project snapshot see
`docs/PROJECT_STATE.md`.

**Naming convention:** `YYYY-MM-DD-<slug>.md` — the date the audit was performed.
